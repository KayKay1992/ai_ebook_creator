Clear Explanation of the View Book Section
This section is the reading mode of your app.
It allows users to open a finished (or in-progress) ebook and read it chapter by chapter in a clean, book-like interface.

1. ViewBookPage
This is the main page that loads when a user opens a book.
What it does:

Gets the book ID from the URL
Fetches the full book data from the backend
Shows a loading skeleton while waiting
If the book exists, it displays the reader
If the book is missing, it shows a “Book not found” message

Think of it as the container page that prepares the book before reading starts.

2. ViewBook
This is the actual reading interface.
What it includes:

A sticky header with the book title and author
Font size controls (A- / A+)
The current chapter title
The chapter content, formatted for comfortable reading
Previous / Next chapter navigation

How reading works:

Only one chapter is shown at a time
Content is formatted so headings, bold text, and italics display properly
Users can increase or decrease text size for comfort
Navigation buttons move between chapters

This component is designed to feel calm, focused, and premium — like a digital book.

3. ViewChapterSidebar
This is the chapter list panel.
What it does:

Shows all chapters in the book
Highlights the currently selected chapter
Lets the user jump directly to any chapter
On mobile, it opens as a slide-in drawer
On desktop, it stays visible beside the reading area

Each chapter is shown with:

A number badge
Chapter title
Chapter position (Chapter 1, Chapter 2, etc.)


How the three components work together

User opens a book → ViewBookPage loads the data
Data is passed to ViewBook
ViewBook shows the reading area
ViewChapterSidebar shows the list of chapters
Clicking a chapter updates the selected chapter and displays its content


Overall purpose
This section turns your generated ebook into a pleasant reading experience, with:

Clean typography
Easy chapter navigation
Mobile-friendly sidebar
Focused, distraction-free layout

It is the final stage after creating, editing, and generating content — the place where the book is actually read
